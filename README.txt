# Zephaniah Talitha Joy P. Iñigo — Birthday Invitation Website

## Files
- `index.html` — main invitation page
- `style.css` — complete responsive design
- `index.html` — countdown, animations, photo album/lightbox, sparkle effect, and map locations
- `invitation-art.png` — uploaded birthday artwork used by the site

## How to open
1. Keep all files in the same folder.
2. Double-click `index.html`.
3. The invitation will open in your browser.
